Human Language Project

A new kind of language for all people on earth

A unified browser-based companion to Wikidata: explore the alphabet, look up words, walk the ontology, browse entities and properties, and transform any English sentence into a Wikidata Q/P sequence — all from a single, theme-aware SPA.

Open the Human Language SPA → View on GitHub Read the README

The six unified modes single-page app

Alphabet

Alphabet

Each letter rendered larger than half the viewport, with IPA pronunciation, keyboard navigation, and direct links into Wikidata.

app.html#mode=alphabet Dictionary

Dictionary

Merged definitions from the Free Dictionary API and Wiktionary, with multilingual support and an "IPA-only" toggle to render meanings phonetically.

app.html#mode=dictionary Ontology

Ontology browser

An expandable tree rooted at entity (Q35120), walking Wikidata's subclass of graph. Cycles are allowed and clearly flagged.

app.html#mode=ontology Entities

Entity browser

Inspect any Wikidata Q-id with multilingual labels, statements, an IPA toggle, and an inline tests button — all theme-aware.

app.html#mode=entity Properties

Property browser

Same lens as the entity browser but for P-ids: definitions, related properties and IPA rendering, with cache-first loading.

app.html#mode=property Transformer

Text → Q/P transformer

Paste any English sentence and watch it become a sequence of Wikidata entities and properties, with n-gram support for multi-word terms.

app.html#mode=transformer
